# SiWu-IoT-Platform 产品需求文档 - 大屏设计模块

## 1. 模块概述

### 1.1 模块名称
**大屏设计模块 (Big Screen Design)**

### 1.2 模块描述
提供强大的可视化大屏设计能力，支持拖拽式组件设计、丰富的组件库、图层管理、样式配置等功能，让用户能够快速创建专业的数据可视化大屏。

### 1.3 技术实现
- **前端框架**: Vue.js 2.6.12 + Element UI
- **图表库**: Echarts 5.4.0 + G2Plot
- **3D渲染**: Three.js
- **拖拽库**: vuedraggable
- **样式处理**: SCSS
- **后端框架**: Spring Boot + MyBatis

## 2. 功能需求

### 2.1 大屏设计器

**功能描述**: 提供直观的大屏设计界面

**详细需求**:
- 左侧组件面板：展示可用的组件库

- 右侧属性面板：组件属性配置区域
- 顶部工具栏：常用操作工具

**界面特性**:
- 响应式布局：适配不同屏幕尺寸

- 快捷键支持：常用操作快捷键

**功能描述**: 管理大屏画布的基本设置

## 3. 接口设计

### 3.1 大屏管理接口

#### 3.1.1 创建大屏
```http
POST /bigscreen
Content-Type: application/json
Authorization: Bearer {token}

{
  "screenName": "物联网监控大屏",
  "screenType": "monitor",
  "width": 1920,
  "height": 1080,
  "backgroundColor": "#0a0a0a",
  "remark": "物联网设备监控大屏"
}
```

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "id": "screen_001",
    "screenName": "物联网监控大屏",
```

## 4. 数据库设计

### 4.1 大屏表 (sys_bigscreen)
```sql
CREATE TABLE sys_bigscreen (
  id varchar(64) NOT NULL COMMENT '大屏ID',
  screen_name varchar(100) NOT NULL COMMENT '大屏名称',
  screen_type varchar(20) DEFAULT 'custom' COMMENT '大屏类型',
  group_id varchar(64) DEFAULT NULL COMMENT '分组ID',
  width int(11) DEFAULT 1920 COMMENT '画布宽度',
  height int(11) DEFAULT 1080 COMMENT '画布高度',
  background_color varchar(20) DEFAULT '#0a0a0a' COMMENT '背景颜色',
  background_image varchar(500) DEFAULT NULL COMMENT '背景图片',
  design_data longtext COMMENT '设计数据JSON',
  publish_status char(1) DEFAULT '0' COMMENT '发布状态（0未发布 1已发布）',
  publish_url varchar(500) DEFAULT NULL COMMENT '发布地址',
  publish_time datetime DEFAULT NULL COMMENT '发布时间',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  KEY idx_group_id (group_id),
  KEY idx_create_by (create_by)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='大屏信息表';
```

### 4.2 大屏分组表 (sys_bigscreen_group)
```sql
CREATE TABLE sys_bigscreen_group (
  id varchar(64) NOT NULL COMMENT '分组ID',
  group_name varchar(100) NOT NULL COMMENT '分组名称',
  parent_id varchar(64) DEFAULT '0' COMMENT '父分组ID',
  order_num int(4) DEFAULT 0 COMMENT '显示顺序',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  KEY idx_parent_id (parent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='大屏分组表';
```

### 4.3 组件表 (sys_component)
```sql
CREATE TABLE sys_component (
  id varchar(64) NOT NULL COMMENT '组件ID',
  component_name varchar(100) NOT NULL COMMENT '组件名称',
  component_type varchar(50) NOT NULL COMMENT '组件类型',
  category varchar(20) NOT NULL COMMENT '组件分类',
  icon varchar(100) DEFAULT NULL COMMENT '组件图标',
  description varchar(500) DEFAULT NULL COMMENT '组件描述',
  default_config text COMMENT '默认配置JSON',
  config_schema text COMMENT '配置模式JSON',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  KEY idx_component_type (component_type),
  KEY idx_category (category)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='组件信息表';
```
