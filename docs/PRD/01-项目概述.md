# SiWu-IoT-Platform 产品需求文档 - 项目概述

## 1. 项目基本信息

### 1.1 项目名称
**SiWu-IoT-Platform (司戊物联网可视化平台)**

### 1.2 项目版本
**v3.8.8**

### 1.3 项目描述
基于RuoYi-Vue 3.8.8和Dataroom 2.0.0集成开发的物联网可视化平台，提供一站式大屏解决方案，从数据源接入到数据清洗处理，再到大屏设计、预览和发布上线的完整流程。

### 1.4 技术架构
- **前端技术栈**: Vue.js 2.6.12、Element UI 2.15.14、Echarts 5.4.0、G2Plot
- **后端技术栈**: Spring Boot 2.5.15、Spring Security 5.7.12、MyBatis Plus、Redis、JWT
- **数据库支持**: MySQL、Oracle、PostgreSQL、ClickHouse、SQL Server、SQLite、TDengine
- **脚本语言**: Groovy、JavaScript
- **其他技术**: Three.js、MQTT、WebSocket

## 2. 项目目标

### 2.1 核心目标
- 提供完整的物联网数据可视化解决方案
- 支持多种数据源接入和数据处理
- 提供强大的大屏设计和编辑能力
- 实现灵活的权限管理和用户控制
- 支持自定义组件开发和扩展

### 2.2 业务价值
- 降低物联网数据可视化开发门槛
- 提高数据展示和分析效率
- 支持快速构建各类监控大屏
- 满足不同行业的数据可视化需求

## 3. 目标用户

### 3.1 主要用户群体
- **系统管理员**: 负责系统配置、用户管理、权限分配
- **数据分析师**: 负责数据源配置、数据集管理、数据清洗
- **大屏设计师**: 负责大屏设计、组件配置、样式调整
- **业务用户**: 负责大屏查看、数据监控、报表分析

### 3.2 使用场景
- 物联网设备监控大屏
- 生产数据实时展示
- 业务指标分析看板
- 运营数据监控中心
- 设备状态预警系统

## 4. 核心功能模块

### 4.1 用户权限管理模块
- 用户管理：用户注册、登录、信息维护
- 角色管理：角色定义、权限分配
- 菜单管理：动态菜单、权限控制
- 数据权限：行级数据权限控制

### 4.2 数据源管理模块
- 多数据库支持：MySQL、Oracle、PostgreSQL等
- 数据源配置：连接测试、参数配置
- 数据源监控：连接状态、性能监控

### 4.3 数据集管理模块
- 原始数据集：直接查询数据库表
- 自助数据集：自定义SQL查询
- 存储过程数据集：调用数据库存储过程
- JSON数据集：静态数据定义
- JS数据集：JavaScript动态数据
- HTTP数据集：第三方API接入
- 脚本数据集：Groovy脚本处理

### 4.4 大屏设计模块
- 可视化设计器：拖拽式组件设计
- 组件库：基础组件、图表组件、装饰组件
- 图层管理：组件层级、组合、锁定
- 样式配置：颜色、字体、动画效果
- 数据绑定：组件与数据集关联

### 4.5 大屏管理模块
- 大屏分组：分类管理多个大屏
- 大屏发布：预览、发布、版本管理
- 大屏权限：访问控制、数据权限
- 模板管理：大屏模板、快速创建

### 4.6 系统管理模块
- 代码生成器：自动生成CRUD代码
- 定时任务：Quartz任务调度
- 系统监控：服务状态、性能监控
- 日志管理：操作日志、错误日志

## 5. 非功能性需求

### 5.1 性能要求
- 支持并发用户数：100+
- 大屏渲染响应时间：< 3秒
- 数据刷新频率：支持1秒级实时刷新
- 系统可用性：99.5%以上

### 5.2 安全要求
- 用户认证：JWT Token认证
- 权限控制：基于RBAC的权限模型
- 数据加密：敏感数据加密存储
- 接口安全：API接口权限验证

### 5.3 兼容性要求
- 浏览器支持：Chrome 70+、Firefox 65+、Safari 12+、Edge 79+
- 分辨率支持：1920x1080、2560x1440、3840x2160
- 移动端适配：响应式设计支持

## 6. 项目约束

### 6.1 技术约束
- 基于开源技术栈，避免商业授权问题
- 支持国产化数据库和操作系统
- 遵循前后端分离架构

### 6.2 业务约束
- 支持多租户架构
- 支持国际化多语言
- 支持主题定制

### 6.3 部署约束
- 支持Docker容器化部署
- 支持集群部署
- 支持云平台部署
