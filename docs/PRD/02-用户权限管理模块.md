# SiWu-IoT-Platform 产品需求文档 - 用户权限管理模块

## 1. 模块概述

### 1.1 模块名称
**用户权限管理模块 (User Permission Management)**

### 1.2 模块描述
基于RBAC（基于角色的访问控制）模型的用户权限管理系统，提供用户管理、角色管理、菜单管理、数据权限等核心功能，确保系统安全性和数据访问控制。

### 1.3 技术实现
- **认证方式**: JWT Token认证
- **权限模型**: RBAC (Role-Based Access Control)
- **数据权限**: 行级数据权限控制
- **前端框架**: Vue.js + Element UI
- **后端框架**: Spring Security + Spring Boot

## 2. 功能需求

### 2.1 用户管理功能

#### 2.1.1 用户注册与登录
**功能描述**: 提供用户注册、登录、登出功能

**详细需求**:
- 用户注册：支持用户名、密码、邮箱注册
- 用户登录：支持用户名/邮箱 + 密码登录
- 登录验证：支持验证码验证
- 密码策略：支持密码复杂度要求
- 登录状态：支持记住登录状态
- 单点登录：支持JWT Token跨域认证

**业务规则**:
- 用户名唯一性校验
- 密码长度不少于6位
- 登录失败5次后锁定账户30分钟
- Token有效期24小时，支持刷新

#### 2.1.2 用户信息管理
**功能描述**: 用户基本信息的增删改查

**详细需求**:
- 用户列表：分页查询用户信息
- 用户详情：查看用户详细信息
- 用户编辑：修改用户基本信息
- 用户删除：软删除用户账户
- 用户状态：启用/禁用用户账户
- 密码重置：管理员重置用户密码

**数据字段**:
```
- 用户ID (userId)
- 用户名 (userName)
- 昵称 (nickName)
- 邮箱 (email)
- 手机号 (phonenumber)
- 性别 (sex)
- 头像 (avatar)
- 密码 (password)
- 状态 (status)
- 删除标志 (delFlag)
- 创建时间 (createTime)
- 更新时间 (updateTime)
- 最后登录时间 (loginDate)
- 最后登录IP (loginIp)
```

#### 2.1.3 用户角色分配
**功能描述**: 为用户分配角色，实现权限继承

**详细需求**:
- 角色分配：为用户分配一个或多个角色
- 角色移除：移除用户的角色权限
- 角色查看：查看用户拥有的角色列表
- 权限预览：预览用户最终权限

### 2.2 角色管理功能

#### 2.2.1 角色定义
**功能描述**: 定义系统中的角色类型和权限范围

**详细需求**:
- 角色创建：创建新的角色
- 角色编辑：修改角色信息
- 角色删除：删除角色定义
- 角色状态：启用/禁用角色
- 角色排序：设置角色优先级

**数据字段**:
```
- 角色ID (roleId)
- 角色名称 (roleName)
- 角色权限 (roleKey)
- 角色排序 (roleSort)
- 数据范围 (dataScope)
- 菜单树选择项是否关联显示 (menuCheckStrictly)
- 部门树选择项是否关联显示 (deptCheckStrictly)
- 角色状态 (status)
- 删除标志 (delFlag)
- 备注 (remark)
- 创建时间 (createTime)
- 更新时间 (updateTime)
```

#### 2.2.2 角色权限分配
**功能描述**: 为角色分配菜单权限和数据权限

**详细需求**:
- 菜单权限：分配角色可访问的菜单
- 数据权限：设置角色数据访问范围
- 权限预览：预览角色权限范围
- 权限继承：支持权限继承关系

**数据权限范围**:
- 全部数据权限：可访问所有数据
- 自定义数据权限：自定义数据范围
- 部门数据权限：仅访问本部门数据
- 部门及以下数据权限：访问本部门及下级部门数据
- 仅本人数据权限：仅访问本人数据

### 2.3 菜单管理功能

#### 2.3.1 菜单结构管理
**功能描述**: 管理系统菜单结构和权限配置

**详细需求**:
- 菜单树：树形结构展示菜单层级
- 菜单添加：添加新的菜单项
- 菜单编辑：修改菜单信息
- 菜单删除：删除菜单项
- 菜单排序：调整菜单显示顺序
- 菜单图标：设置菜单图标

**数据字段**:
```
- 菜单ID (menuId)
- 菜单名称 (menuName)
- 父菜单ID (parentId)
- 显示顺序 (orderNum)
- 路由地址 (path)
- 组件路径 (component)
- 路由参数 (query)
- 是否为外链 (isFrame)
- 是否缓存 (isCache)
- 菜单类型 (menuType)
- 菜单状态 (visible)
- 菜单状态 (status)
- 权限标识 (perms)
- 菜单图标 (icon)
- 创建时间 (createTime)
- 更新时间 (updateTime)
```

#### 2.3.2 菜单权限控制
**功能描述**: 基于菜单权限控制用户访问

**详细需求**:
- 权限标识：为菜单设置权限标识
- 权限验证：验证用户菜单访问权限
- 动态菜单：根据权限动态生成菜单
- 按钮权限：控制页面按钮显示

### 2.4 数据权限功能

#### 2.4.1 数据权限控制
**功能描述**: 实现行级数据权限控制

**详细需求**:
- 数据范围：设置用户数据访问范围
- 部门权限：基于部门的数据权限
- 个人权限：基于个人的数据权限
- 自定义权限：自定义数据权限规则

#### 2.4.2 权限验证
**功能描述**: 在数据访问时进行权限验证

**详细需求**:
- 查询权限：验证数据查询权限
- 修改权限：验证数据修改权限
- 删除权限：验证数据删除权限
- 权限拦截：自动拦截无权限操作

## 3. 接口设计

### 3.1 用户管理接口

#### 3.1.1 用户登录
```http
POST /login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin123",
  "code": "1234",
  "uuid": "uuid-string"
}
```

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功",
  "token": "eyJhbGciOiJIUzUxMiJ9..."
}
```

#### 3.1.2 获取用户信息
```http
GET /getInfo
Authorization: Bearer {token}
```

**响应示例**:
```json
{
  "code": 200,
  "user": {
    "userId": 1,
    "userName": "admin",
    "nickName": "管理员",
    "email": "admin@example.com",
    "phonenumber": "15888888888",
    "sex": "1",
    "avatar": "",
    "roles": ["admin"],
    "permissions": ["*:*:*"]
  }
}
```

#### 3.1.3 用户列表查询
```http
GET /system/user/list?pageNum=1&pageSize=10&userName=admin
Authorization: Bearer {token}
```

### 3.2 角色管理接口

#### 3.2.1 角色列表查询
```http
GET /system/role/list?pageNum=1&pageSize=10
Authorization: Bearer {token}
```

#### 3.2.2 角色权限分配
```http
PUT /system/role/changeStatus
Content-Type: application/json
Authorization: Bearer {token}

{
  "roleId": 1,
  "status": "0"
}
```

### 3.3 菜单管理接口

#### 3.3.1 菜单树查询
```http
GET /system/menu/treeselect
Authorization: Bearer {token}
```

#### 3.3.2 角色菜单权限
```http
GET /system/menu/roleMenuTreeselect/{roleId}
Authorization: Bearer {token}
```

## 4. 数据库设计

### 4.1 用户表 (sys_user)
```sql
CREATE TABLE sys_user (
  user_id bigint(20) NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  user_name varchar(30) NOT NULL COMMENT '用户账号',
  nick_name varchar(30) NOT NULL COMMENT '用户昵称',
  email varchar(50) DEFAULT '' COMMENT '用户邮箱',
  phonenumber varchar(11) DEFAULT '' COMMENT '手机号码',
  sex char(1) DEFAULT '0' COMMENT '用户性别（0男 1女 2未知）',
  avatar varchar(100) DEFAULT '' COMMENT '头像地址',
  password varchar(100) DEFAULT '' COMMENT '密码',
  status char(1) DEFAULT '0' COMMENT '帐号状态（0正常 1停用）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0代表存在 2代表删除）',
  login_ip varchar(128) DEFAULT '' COMMENT '最后登录IP',
  login_date datetime DEFAULT NULL COMMENT '最后登录时间',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户信息表';
```

### 4.2 角色表 (sys_role)
```sql
CREATE TABLE sys_role (
  role_id bigint(20) NOT NULL AUTO_INCREMENT COMMENT '角色ID',
  role_name varchar(30) NOT NULL COMMENT '角色名称',
  role_key varchar(100) NOT NULL COMMENT '角色权限字符串',
  role_sort int(4) NOT NULL COMMENT '显示顺序',
  data_scope char(1) DEFAULT '1' COMMENT '数据范围（1：全部数据权限 2：自定数据权限 3：本部门数据权限 4：本部门及以下数据权限）',
  menu_check_strictly tinyint(1) DEFAULT 1 COMMENT '菜单树选择项是否关联显示',
  dept_check_strictly tinyint(1) DEFAULT 1 COMMENT '部门树选择项是否关联显示',
  status char(1) NOT NULL COMMENT '角色状态（0正常 1停用）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0代表存在 2代表删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (role_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='角色信息表';
```

### 4.3 菜单表 (sys_menu)
```sql
CREATE TABLE sys_menu (
  menu_id bigint(20) NOT NULL AUTO_INCREMENT COMMENT '菜单ID',
  menu_name varchar(50) NOT NULL COMMENT '菜单名称',
  parent_id bigint(20) DEFAULT 0 COMMENT '父菜单ID',
  order_num int(4) DEFAULT 0 COMMENT '显示顺序',
  path varchar(200) DEFAULT '' COMMENT '路由地址',
  component varchar(255) DEFAULT NULL COMMENT '组件路径',
  query varchar(255) DEFAULT NULL COMMENT '路由参数',
  is_frame int(1) DEFAULT 1 COMMENT '是否为外链（0是 1否）',
  is_cache int(1) DEFAULT 0 COMMENT '是否缓存（0缓存 1不缓存）',
  menu_type char(1) DEFAULT '' COMMENT '菜单类型（M目录 C菜单 F按钮）',
  visible char(1) DEFAULT 0 COMMENT '菜单状态（0显示 1隐藏）',
  status char(1) DEFAULT 0 COMMENT '菜单状态（0正常 1停用）',
  perms varchar(100) DEFAULT NULL COMMENT '权限标识',
  icon varchar(100) DEFAULT '#' COMMENT '菜单图标',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT '' COMMENT '备注',
  PRIMARY KEY (menu_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='菜单权限表';
```
