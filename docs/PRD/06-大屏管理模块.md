# SiWu-IoT-Platform 产品需求文档 - 大屏管理模块

## 1. 模块概述

### 1.1 模块名称
**大屏管理模块 (Big Screen Management)**

### 1.2 模块描述
提供大屏的完整生命周期管理，包括大屏分组、大屏发布、权限控制、版本管理、模板管理等功能，确保大屏项目的有效组织和安全访问。

### 1.3 技术实现
- **前端框架**: Vue.js + Element UI
- **后端框架**: Spring Boot + MyBatis
- **权限控制**: Spring Security + JWT
- **文件存储**: 本地存储 + 云存储
- **版本控制**: Git版本管理

## 2. 功能需求

### 2.1 大屏分组管理

#### 2.1.1 分组结构管理
**功能描述**: 管理大屏的分组结构

**详细需求**:
- 分组创建：创建新的大屏分组
- 分组编辑：修改分组名称和描述
- 分组删除：删除不需要的分组
- 分组移动：调整分组层级结构
- 分组排序：设置分组显示顺序

**分组特性**:
- 树形结构：支持多级分组
- 分组图标：为分组设置图标
- 分组描述：添加分组描述信息
- 分组权限：设置分组访问权限

**功能描述**: 控制用户对分组的访问权限

**详细需求**:

```http

Content-Type: application/json
Authorization: Bearer {token}

{
  "groupName": "物联网监控",
  "parentId": "0",
  "orderNum": 1,
  "remark": "物联网设备监控分组"
```

## 4. 数据库设计

### 4.1 大屏分组表 (sys_bigscreen_group)
```sql
CREATE TABLE sys_bigscreen_group (
  id varchar(64) NOT NULL COMMENT '分组ID',
  group_name varchar(100) NOT NULL COMMENT '分组名称',
  parent_id varchar(64) DEFAULT '0' COMMENT '父分组ID',
  order_num int(4) DEFAULT 0 COMMENT '显示顺序',
  group_icon varchar(100) DEFAULT NULL COMMENT '分组图标',
  group_description varchar(500) DEFAULT NULL COMMENT '分组描述',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  KEY idx_parent_id (parent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='大屏分组表';
```

### 4.2 大屏发布记录表 (sys_bigscreen_publish)
```sql
CREATE TABLE sys_bigscreen_publish (
  id varchar(64) NOT NULL COMMENT '发布记录ID',
  screen_id varchar(64) NOT NULL COMMENT '大屏ID',
  version varchar(20) NOT NULL COMMENT '版本号',
  publish_type varchar(20) DEFAULT 'public' COMMENT '发布类型',
  access_password varchar(100) DEFAULT NULL COMMENT '访问密码',
  publish_url varchar(500) DEFAULT NULL COMMENT '发布地址',
  publish_config text COMMENT '发布配置JSON',
  publish_status char(1) DEFAULT '1' COMMENT '发布状态（0失败 1成功）',
  publish_time datetime DEFAULT NULL COMMENT '发布时间',
  publish_by varchar(64) DEFAULT '' COMMENT '发布者',
  rollback_time datetime DEFAULT NULL COMMENT '回滚时间',
  rollback_by varchar(64) DEFAULT NULL COMMENT '回滚者',
  PRIMARY KEY (id),
  KEY idx_screen_id (screen_id),
  KEY idx_version (version),
  KEY idx_publish_time (publish_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='大屏发布记录表';
```

### 4.3 大屏权限表 (sys_bigscreen_permission)
```sql
CREATE TABLE sys_bigscreen_permission (
  id varchar(64) NOT NULL COMMENT '权限ID',
  screen_id varchar(64) NOT NULL COMMENT '大屏ID',
  permission_type varchar(20) NOT NULL COMMENT '权限类型',
  access_type varchar(20) DEFAULT 'public' COMMENT '访问类型',
  access_password varchar(100) DEFAULT NULL COMMENT '访问密码',
  allowed_users text COMMENT '允许用户列表JSON',
  allowed_roles text COMMENT '允许角色列表JSON',
  access_time_config text COMMENT '访问时间配置JSON',
  ip_whitelist text COMMENT 'IP白名单JSON',
  max_access_count int(11) DEFAULT NULL COMMENT '最大访问次数',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (id),
  UNIQUE KEY uk_screen_id (screen_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='大屏权限表';
```

### 4.5 大屏访问记录表 (sys_bigscreen_access_log)
```sql
CREATE TABLE sys_bigscreen_access_log (
  id varchar(64) NOT NULL COMMENT '访问记录ID',
  screen_id varchar(64) NOT NULL COMMENT '大屏ID',
  user_id bigint(20) DEFAULT NULL COMMENT '用户ID',
  user_name varchar(50) DEFAULT NULL COMMENT '用户名',
  access_time datetime NOT NULL COMMENT '访问时间',
  access_duration int(11) DEFAULT NULL COMMENT '访问时长(秒)',
  client_ip varchar(50) DEFAULT NULL COMMENT '客户端IP',
  user_agent varchar(500) DEFAULT NULL COMMENT '用户代理',
  referer varchar(500) DEFAULT NULL COMMENT '来源页面',
  access_result char(1) DEFAULT '1' COMMENT '访问结果（0失败 1成功）',
  error_message varchar(500) DEFAULT NULL COMMENT '错误信息',
  PRIMARY KEY (id),
  KEY idx_screen_id (screen_id),
  KEY idx_user_id (user_id),
  KEY idx_access_time (access_time)
```
