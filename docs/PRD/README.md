## 🎯 项目特色

### 技术特色
- **前后端分离**: Vue.js + Spring Boot架构
- **多数据源支持**: MySQL、Oracle、PostgreSQL、ClickHouse等
- **丰富组件库**: 基础组件、图表组件、装饰组件
- **可视化设计**: 拖拽式大屏设计器
- **权限控制**: 基于RBAC的权限管理
- **代码生成**: 自动生成CRUD代码

### 功能特色
- **一站式解决方案**: 从数据接入到大屏发布的完整流程
- **多种数据集类型**: 原始数据、自定义SQL、存储过程、JSON、JS脚本等
- **实时数据刷新**: 支持实时数据更新和定时刷新
- **大屏分组管理**: 支持大屏分类和权限控制
- **模板化管理**: 提供大屏模板和快速创建功能
- **系统监控**: 完整的系统监控和告警机制

## 🏗️ 系统架构

### 前端架构
```
Vue.js 2.6.12
├── Element UI 2.15.14 (UI组件库)
├── Echarts 5.4.0 (图表库)
├── G2Plot (图表库)
├── Three.js (3D渲染)
└── 自定义组件库
```

### 后端架构
```
Spring Boot 2.5.15
├── Spring Security 5.7.12 (安全框架)
├── MyBatis Plus (ORM框架)
├── Redis (缓存)
├── Quartz (定时任务)
├── Druid (连接池)
└── JWT (认证)
```

### 数据库支持
- MySQL 5.7+
- Oracle 11g+
- PostgreSQL 10+
- ClickHouse 20+
- SQL Server 2016+
- SQLite 3+
- TDengine 2.0+

## 📊 核心功能流程

### 数据可视化流程
```
数据源接入 → 数据集配置 → 大屏设计 → 大屏发布 → 数据监控
```

### 用户权限流程
```
用户注册 → 角色分配 → 权限配置 → 访问控制 → 操作审计
```

### 大屏设计流程
```
选择模板 → 拖拽组件 → 配置样式 → 绑定数据 → 预览发布
```

## 📈 性能指标

### 系统性能
- 支持并发用户数: 100+
- 大屏渲染响应时间: < 3秒
- 数据刷新频率: 支持1秒级实时刷新
- 系统可用性: 99.5%以上

### 数据性能
- 支持数据源连接数: 50+
- 单次查询数据量: 100万条
- 数据缓存命中率: 85%+
- 查询响应时间: < 2秒
