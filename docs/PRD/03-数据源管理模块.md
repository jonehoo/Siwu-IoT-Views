# SiWu-IoT-Platform 产品需求文档 - 数据源管理模块

## 1. 模块概述

### 1.1 模块名称
**数据源管理模块 (DataSource Management)**

### 1.2 模块描述
提供多种数据源的连接、配置、测试和管理功能，支持主流数据库、文件数据源和第三方API接入，为数据可视化提供统一的数据接入层。

### 1.3 技术实现
- **连接池**: Druid数据库连接池
- **数据库驱动**: 支持多种数据库驱动
- **连接管理**: 动态数据源切换
- **前端框架**: Vue.js + Element UI
- **后端框架**: Spring Boot + MyBatis

## 2. 功能需求

### 2.1 数据源类型支持

#### 2.1.1 关系型数据库
**支持的数据源类型**:
- **MySQL**: 最常用的开源关系型数据库
- **PostgreSQL**: 功能强大的开源数据库
- **Oracle**: 企业级关系型数据库
- **SQL Server**: 微软企业级数据库
- **ClickHouse**: 列式存储数据库，适合OLAP场景
- **TDengine**: 时序数据库，适合IoT场景
- **SQLite**: 轻量级嵌入式数据库

#### 2.1.2 文件数据源
- **Excel文件**: 支持.xlsx、.xls格式
- **CSV文件**: 支持逗号分隔值文件
- **JSON文件**: 支持JSON格式数据文件

#### 2.1.3 第三方API
- **HTTP接口**: RESTful API接入
- **WebSocket**: 实时数据流接入
- **MQTT**: 物联网消息队列接入

### 2.2 数据源配置功能

#### 2.2.1 数据源创建
**功能描述**: 创建新的数据源连接

**详细需求**:
- 数据源类型选择：从支持的类型中选择
- 连接参数配置：根据类型配置相应参数
- 连接测试：验证数据源连接是否正常
- 高级设置：连接池、超时等高级参数
- 数据源命名：设置数据源名称和描述

**配置参数**:
```
基础参数:
- 数据源名称 (sourceName)
- 数据源类型 (sourceType)
- 连接地址 (url)
- 用户名 (username)
- 密码 (password)
- 驱动类名 (driverClassName)

高级参数:
- 连接池初始大小 (initialSize)
- 连接池最大连接数 (maxActive)
- 连接池最小空闲连接数 (minIdle)
- 连接超时时间 (connectionTimeout)
- 查询超时时间 (queryTimeout)
- 连接验证查询 (validationQuery)
```

#### 2.2.2 数据源编辑
**功能描述**: 修改现有数据源配置

**详细需求**:
- 参数修改：修改连接参数
- 连接重试：重新测试连接
- 配置保存：保存修改后的配置
- 版本管理：记录配置变更历史

#### 2.2.3 数据源删除
**功能描述**: 删除不需要的数据源

**详细需求**:
- 删除确认：确认删除操作
- 依赖检查：检查是否有数据集依赖
- 级联删除：处理依赖关系
- 软删除：支持数据源恢复

### 2.3 数据源测试功能

#### 2.3.1 连接测试
**功能描述**: 测试数据源连接是否正常

**详细需求**:
- 连接验证：验证连接参数正确性
- 权限验证：验证用户权限是否足够
- 网络测试：测试网络连通性
- 性能测试：测试连接响应时间

**测试结果**:
```
- 连接状态：成功/失败
- 响应时间：连接耗时
- 错误信息：详细错误描述
- 建议操作：修复建议
```

#### 2.3.2 数据预览
**功能描述**: 预览数据源中的数据

**详细需求**:
- 表列表：显示数据库中的表
- 字段信息：显示表结构信息
- 数据预览：预览表数据内容
- 数据统计：显示数据量统计

### 2.4 数据源监控功能

#### 2.4.1 连接状态监控
**功能描述**: 监控数据源连接状态

**详细需求**:
- 实时状态：显示当前连接状态
- 连接数统计：显示活跃连接数
- 性能指标：显示连接性能数据
- 异常告警：连接异常时告警

#### 2.4.2 使用情况统计
**功能描述**: 统计数据源使用情况

**详细需求**:
- 使用频率：统计数据源使用次数
- 查询统计：统计查询次数和耗时
- 用户统计：统计使用用户数
- 趋势分析：分析使用趋势

## 5. 数据库设计

### 5.1 数据源表 (sys_datasource)
```sql
CREATE TABLE sys_datasource (
  id varchar(64) NOT NULL COMMENT '数据源ID',
  source_name varchar(100) NOT NULL COMMENT '数据源名称',
  source_type varchar(20) NOT NULL COMMENT '数据源类型',
  driver_class_name varchar(200) NOT NULL COMMENT '驱动类名',
  url varchar(500) NOT NULL COMMENT '连接地址',
  username varchar(100) DEFAULT NULL COMMENT '用户名',
  password varchar(200) DEFAULT NULL COMMENT '密码',
  config text COMMENT '高级配置JSON',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  UNIQUE KEY uk_source_name (source_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据源配置表';
```

### 5.2 数据源使用记录表 (sys_datasource_usage)
```sql
CREATE TABLE sys_datasource_usage (
  id varchar(64) NOT NULL COMMENT '记录ID',
  datasource_id varchar(64) NOT NULL COMMENT '数据源ID',
  user_id bigint(20) NOT NULL COMMENT '用户ID',
  operation_type varchar(20) NOT NULL COMMENT '操作类型',
  operation_time datetime NOT NULL COMMENT '操作时间',
  response_time int(11) DEFAULT NULL COMMENT '响应时间(ms)',
  success_flag char(1) DEFAULT '1' COMMENT '是否成功（0失败 1成功）',
  error_message text COMMENT '错误信息',
  PRIMARY KEY (id),
  KEY idx_datasource_id (datasource_id),
  KEY idx_user_id (user_id),
  KEY idx_operation_time (operation_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据源使用记录表';
```
