# SiWu-IoT-Platform 产品需求文档 - 数据集管理模块

## 1. 模块概述

### 1.1 模块名称
**数据集管理模块 (Dataset Management)**

### 1.2 模块描述
提供多种类型的数据集创建、配置和管理功能，支持从原始数据到处理后的可视化数据的完整数据处理流程，为大屏组件提供统一的数据接口。

### 1.3 技术实现
- **数据处理**: Groovy脚本、JavaScript、SQL
- **数据缓存**: Redis缓存机制
- **数据转换**: 多种数据格式转换
- **前端框架**: Vue.js + Element UI
- **后端框架**: Spring Boot + MyBatis

## 2. 功能需求

### 2.1 数据集类型支持

#### 2.1.1 原始数据集 (Original Dataset)
**功能描述**: 直接查询数据库表，获取原始数据

**详细需求**:
- 数据源选择：选择已配置的数据源
- 表选择：选择要查询的数据表
- 字段选择：选择需要的字段
- 条件过滤：设置查询条件
- 排序设置：设置排序规则
- 分页设置：设置分页参数

**配置参数**:
```json
{
  "datasetType": "original",
  "datasetName": "用户数据表",
  "datasourceId": "datasource_001",
  "tableName": "sys_user",
  "columns": ["user_id", "user_name", "nick_name", "email", "create_time"],
  "whereClause": "status = '0'",
  "orderBy": "create_time DESC",
  "limit": 1000
}
```

#### 2.1.2 自助数据集 (Custom Dataset)
**功能描述**: 自定义SQL语句查询数据

**详细需求**:
- SQL编辑器：提供SQL编辑界面
- 语法高亮：SQL语法高亮显示
- 参数绑定：支持参数化查询
- 查询预览：实时预览查询结果
- 性能优化：查询性能分析

**配置参数**:
```json
{
  "datasetType": "custom",
  "datasetName": "用户统计查询",
  "datasourceId": "datasource_001",
  "sql": "SELECT DATE(create_time) as date, COUNT(*) as user_count FROM sys_user WHERE create_time >= ? GROUP BY DATE(create_time) ORDER BY date DESC",
  "parameters": [
    {
      "name": "startDate",
      "type": "date",
      "defaultValue": "2024-01-01"
    }
  ]
}
```

#### 2.1.3 存储过程数据集 (Stored Procedure Dataset)
**功能描述**: 调用数据库存储过程获取数据

**详细需求**:
- 存储过程选择：选择数据库存储过程
- 参数配置：配置存储过程参数
- 结果集处理：处理存储过程返回结果
- 错误处理：处理存储过程异常

**配置参数**:
```json
{
  "datasetType": "storedProcedure",
  "datasetName": "用户分析报表",
  "datasourceId": "datasource_001",
  "procedureName": "sp_user_analysis",
  "parameters": [
    {
      "name": "start_date",
      "type": "date",
      "value": "2024-01-01"
    },
    {
      "name": "end_date",
      "type": "date",
      "value": "2024-12-31"
    }
  ]
}
```

#### 2.1.4 JSON数据集 (JSON Dataset)
**功能描述**: 定义静态JSON数据

**详细需求**:
- JSON编辑器：提供JSON编辑界面
- 数据验证：JSON格式验证
- 数据预览：预览JSON数据
- 数据导入：支持从文件导入JSON

**配置参数**:
```json
{
  "datasetType": "json",
  "datasetName": "静态配置数据",
  "data": [
    {
      "name": "北京",
      "value": 100,
      "category": "一线城市"
    },
    {
      "name": "上海",
      "value": 95,
      "category": "一线城市"
    }
  ]
}
```

#### 2.1.5 JS数据集 (JavaScript Dataset)
**功能描述**: 使用JavaScript代码生成动态数据

**详细需求**:
- JS编辑器：提供JavaScript编辑界面
- 代码执行：安全执行JavaScript代码
- 数据生成：生成符合格式的数据
- 调试功能：提供调试和日志功能

**配置参数**:
```json
{
  "datasetType": "js",
  "datasetName": "随机数据生成",
  "script": "function generateData() { return Array.from({length: 10}, (_, i) => ({ name: 'Item ' + i, value: Math.random() * 100 })); }",
  "refreshInterval": 5000
}
```

#### 2.1.6 HTTP数据集 (HTTP Dataset)
**功能描述**: 调用第三方HTTP接口获取数据

**详细需求**:
- URL配置：配置HTTP请求URL
- 请求方法：支持GET、POST等方法
- 请求头配置：配置请求头信息
- 参数配置：配置请求参数
- 响应处理：处理HTTP响应数据

**配置参数**:
```json
{
  "datasetType": "http",
  "datasetName": "天气数据接口",
  "url": "https://api.weather.com/v1/current",
  "method": "GET",
  "headers": {
    "Authorization": "Bearer {token}",
    "Content-Type": "application/json"
  },
  "parameters": {
    "city": "Beijing",
    "unit": "metric"
  },
  "refreshInterval": 300000
}
```

#### 2.1.7 脚本数据集 (Script Dataset)
**功能描述**: 使用Groovy脚本处理复杂数据逻辑

**详细需求**:
- Groovy编辑器：提供Groovy脚本编辑
- 数据源访问：访问多个数据源
- 数据处理：复杂数据处理逻辑
- 结果返回：返回处理后的数据

**配置参数**:
```json
{
  "datasetType": "script",
  "datasetName": "复杂数据处理",
  "script": "import groovy.sql.Sql\nimport groovy.json.JsonBuilder\n\n// 连接数据库\nSql sql = Sql.newInstance('jdbc:mysql://localhost:3306/test', 'root', 'password', 'com.mysql.jdbc.Driver')\n\n// 查询数据\nList<Map> data = sql.rows('SELECT * FROM user WHERE status = ?', ['active'])\n\n// 数据处理\nList<Map> result = data.collect { row ->\n    [\n        name: row.user_name,\n        age: calculateAge(row.birth_date),\n        department: getDepartment(row.dept_id)\n    ]\n}\n\nreturn result"
}
```

## 4. 数据库设计

### 4.1 数据集表 (sys_dataset)
```sql
CREATE TABLE sys_dataset (
  id varchar(64) NOT NULL COMMENT '数据集ID',
  dataset_name varchar(100) NOT NULL COMMENT '数据集名称',
  dataset_type varchar(20) NOT NULL COMMENT '数据集类型',
  datasource_id varchar(64) DEFAULT NULL COMMENT '数据源ID',
  config text NOT NULL COMMENT '数据集配置JSON',
  status char(1) DEFAULT '1' COMMENT '状态（0停用 1正常）',
  del_flag char(1) DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  create_by varchar(64) DEFAULT '' COMMENT '创建者',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新者',
  update_time datetime DEFAULT NULL COMMENT '更新时间',
  remark varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  UNIQUE KEY uk_dataset_name (dataset_name),
  KEY idx_datasource_id (datasource_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据集配置表';
```

### 4.2 数据集执行记录表 (sys_dataset_execution)
```sql
CREATE TABLE sys_dataset_execution (
  id varchar(64) NOT NULL COMMENT '执行记录ID',
  dataset_id varchar(64) NOT NULL COMMENT '数据集ID',
  user_id bigint(20) NOT NULL COMMENT '用户ID',
  execution_time datetime NOT NULL COMMENT '执行时间',
  response_time int(11) DEFAULT NULL COMMENT '响应时间(ms)',
  data_count int(11) DEFAULT NULL COMMENT '数据条数',
  success_flag char(1) DEFAULT '1' COMMENT '是否成功（0失败 1成功）',
  error_message text COMMENT '错误信息',
  parameters text COMMENT '执行参数JSON',
  PRIMARY KEY (id),
  KEY idx_dataset_id (dataset_id),
  KEY idx_user_id (user_id),
  KEY idx_execution_time (execution_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据集执行记录表';
```

### 4.3 数据集缓存表 (sys_dataset_cache)
```sql
CREATE TABLE sys_dataset_cache (
  id varchar(64) NOT NULL COMMENT '缓存ID',
  dataset_id varchar(64) NOT NULL COMMENT '数据集ID',
  cache_key varchar(200) NOT NULL COMMENT '缓存键',
  cache_data longtext COMMENT '缓存数据JSON',
  expire_time datetime NOT NULL COMMENT '过期时间',
  create_time datetime DEFAULT NULL COMMENT '创建时间',
  PRIMARY KEY (id),
  UNIQUE KEY uk_cache_key (cache_key),
  KEY idx_dataset_id (dataset_id),
  KEY idx_expire_time (expire_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据集缓存表';
```
